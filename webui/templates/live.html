How to read this page

  • Market lag: minutes since the latest candle inside the tracked kline file.
  • Forecast lag: minutes since the first predicted step currently shown on the card.
  • Pred move: expected next-step move from the prediction rule used by that horizon.

Honest caveat

Inference is fresh, but only as fresh as the local candle files.

The page reruns local finetuned inference from Binance-refreshed candle files when the API is reachable. If Binance is unavailable, it falls back to the most recent cached or local file and shows that on the card.
